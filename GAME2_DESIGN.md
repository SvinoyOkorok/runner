# Игра 2: Endless Runner — Техническое задание

Статус: утверждено 15.11
Цель: закрыть анимации (Animator), звук (AudioSource), Save/Load (PlayerPrefs); закрепить события, GameManager без синглтона, UI, билд.

## Механика

- Персонаж бежит вправо автоматически, мир скроллится влево (или персонаж реально бежит по статичному полу — решить на старте)
- Игрок: прыжок (Space / тап) с одинарной высотой, приземление на платформы/пол
- Препятствия (шипы/ящики): касание = смерть
- Монеты на земле и в воздухе: сбор за очки
- Скорость бега растёт со временем (плавно)
- Счёт: 1 монета = 10 очков + бонус за расстояние (1 метр = 1 очко)
- Экран смерти: текущий счёт + BEST (из сохранения) + рестарт

## Целевые темы (критерии приёмки)

| Тема | Требование |
|---|---|
| Animator | State Machine: Idle → Run → Jump → Dead; переходы по параметрам (bool isGrounded, trigger die); без магических строк — параметры через константы |
| Звук | Минимум 3 SFX (прыжок, монета, смерть) + фоновая музыка (loop); AudioManager через события, не через ссылки из каждого скрипта |
| Save/Load | PlayerPrefs: ключ "best_score", запись при смерти, чтение при старте; показ рекорда на экране смерти |
| Архитектура | События GameManager↔UI/AudioManager; зависимости через инспектор; без синглтонов и FindObjectOfType |
| UI | Счёт в игре, экран смерти, адаптивность (Scale With Screen Size) |
| Билд | WebGL, проверка всех механик в сборке |

## Структура скриптов (предварительная)

- `Player` — движение/прыжок (Rigidbody2D), анимация, событие смерти
- `GroundScroller` / `SpawnManager` — бесконечный пол и спавн препятствий/монет из пула
- `GameManager` — счёт, скорость мира, состояния (игра/смерть), события
- `UIManager` — счёт, экран смерти (подписан на события)
- `AudioManager` — SFX и музыка (подписан на события)
- `SaveSystem` — обёртка над PlayerPrefs (чтобы GameManager не знал о деталях хранения)

## Вне скоупа (сдерживаемся)

Враги с ИИ, боссы, магазин, скины, несколько биомов, реклама, мобильный ввод.
